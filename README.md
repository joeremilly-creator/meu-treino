# Meu Treino

App pessoal de treino, sem login. Abre no celular e pode ser instalado na tela inicial.

- **Treinos**: protocolo com 3 treinos, modo guiado com séries, carga, repetições e timer de descanso.
- **Guia**: infográfico (posição inicial → final) e passo a passo de cada exercício.
- **Desempenho**: evolução de carga por exercício, treinos por semana, peso corporal, recordes e histórico.
- **Ajustes**: backup/importação dos dados (.json) e edição de séries/repetições.

Os dados ficam salvos só no aparelho (localStorage). Faça backup em Ajustes de vez em quando.
